# Development Roadmap – Planora AI

This document outlines the strategic engineering roadmap for Planora AI as it progresses from v1.0.0 to commercial enterprise scale.

---

## 1. Version 1.0.0 (Current Release – October 2026)

- [x] Full-stack architecture with FastAPI backend and responsive Vanilla JS/CSS frontend.
- [x] Firebase Authentication (Email/Password & Google OAuth) with server-side ID token validation.
- [x] Cloud Firestore database support with in-memory zero-config dev fallback.
- [x] AI Event Studio with Groq LLaMA 3.1 structured Pydantic output validation.
- [x] Transparent offline Demonstration Mode fallback.
- [x] Budget Management with real-time utilization and Chart.js category visualizations.
- [x] Milestone countdown roadmap and day-of hourly run-sheet.
- [x] Task Management with priority filters and instant dashboard synchronization.
- [x] Vendor Roster tracking quotes and booking statuses.
- [x] Guest Management tracking RSVPs, dietary notes, and +1 attendance counts.
- [x] AI Event Copilot grounded in active event budget and timeline context.
- [x] Executive Master Report with CSV exports and print-ready PDF styling.
- [x] Comprehensive documentation library and automated test suite.

---

## 2. Version 1.1.0 (Q1 2027 – Collaboration & Smart Comms)

- [ ] **Multi-User Collaboration**: Invite co-planners, family members, or clients to an event workspace with specific roles (`Admin`, `Editor`, `Viewer`).
- [ ] **Direct WhatsApp RSVP Integration**: Allow guests to confirm attendance via official WhatsApp Business API buttons.
- [ ] **Custom Event Public Landing Pages**: Generate a personalized public RSVP webpage for guests with event schedules, dress codes, and directions.
- [ ] **Vendor Directory & Quote Comparison**: Direct vendor catalog filtering by city and verified user reviews.

---

## 3. Version 1.2.0 (Q2 2027 – Commercial Monetization & FinTech)

- [ ] **Stripe & Razorpay Billing Integration**: Automated recurring subscriptions for Pro Planner (₹1,499/mo) and Agency tiers.
- [ ] **Direct Vendor Escrow & Advance Payments**: Built-in UPI and card payment receipts linked directly to expense records.
- [ ] **Multi-Language Regional Support**: Full UI localization in Hindi, Gujarati, Tamil, Telugu, and Spanish.
- [ ] **Offline PWA Support**: ServiceWorker caching for event run-sheets in low-connectivity venue banquet halls.
